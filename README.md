# 積算 AI アシスト（モック）

東京油機工業様「AI 活用ご相談」議事録（2026-08-19）をもとに、提案するシステムの UI/UX を体験できるモックアプリです。
**バックエンド・AI 接続はなく、すべてブラウザ内のモックデータで動作します。** 機種名・数値・自治体名は架空です。

## 画面と議事録の対応

| 画面 | パス | 議事録テーマ | フェーズ |
| --- | --- | --- | --- |
| ダッシュボード | `/` | KPI・学習状況・フェーズ定義 | — |
| 積算判定アシスト | `/inquiries`, `/inquiries/[id]` | №1 AI の「弟子入り」（回答案 → 担当者が承認／修正／相談） | 第1 |
| 資料 品質チェック | `/quality` | №3 抜け漏れ・外れ値・不整合の指摘 | 第1 |
| 標準化・仕様への昇格 | `/knowledge` | №2 例外対応を束ねて標準仕様へ昇格提案 | 第1〜2 |
| 図面直読 | `/drawings` | №4 マルチモーダル図面読取 | 第2（プレビュー） |
| Web 一次回答 | `/web-answer` | №5 Web 一次回答／№6 AI 向けデータセット | 第3（構想） |
| 動画マニュアル生成 | `/manuals` | №7 動画→作業手順書 | 第0（先行） |
| モデル接続・利用上限 | `/settings` | 複数 API 切替・ローカル予備・従量課金上限・セキュリティ | — |
| 操作ガイド | `/guide` | 新人向けシステムマニュアル（画面の見方・1日の流れ・用語集・FAQ） | — |

## 起動

```bash
npm install
npm run dev
```

## 構成

- `src/lib/types.ts` … ドメイン型
- `src/lib/mock-data.ts` … モックデータ（案件・品質指摘・昇格候補・モデル・マニュアル）
- `src/lib/inquiry-store.tsx` … 案件のレビュー状態（承認／修正／相談）をセッション内で保持する Context
- `src/components/` … 共通 UI（サイドバー、カード、バッジ等）
- `src/app/` … 各画面（App Router）
